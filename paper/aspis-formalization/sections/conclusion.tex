\section{Conclusion}
\label{sec:conclusion}

Aspis connects a transparent private-spend argument to every successful
execution of its deployed verifier.  For any translated Rust call that returns
success, Lean
derives the statement digest, transcript, work checks, queries, authenticated
openings, four low-degree folds, final polynomial, full algebraic claim table,
relation rounds, and both final accumulators.  The proof obtains these facts
from the same run and then connects them to the spend relation and
nullifier-controlled state model.

The security result uses one probability experiment and a checked failure
decomposition.  Under the published decoding and Fiat--Shamir results, the
work-normalized protocol budget is at most \(0.7\cdot2^{-100}\).  Primitive
and credential bounds totaling at most \(0.3\cdot2^{-100}\), together with
the stated implementation and runtime correspondences, give the conditional
\(2^{-100}\) bound.  The raw accounting keeps the completed grinding work out
of the exponent and exposes the remaining terms.

The public evidence package makes the result reproducible at each boundary: a
331-module theorem replay, pinned Rust translation, deterministic program
build, archived proof and statement, and finalized mainnet state transition.
The two remaining composition tasks are precise: identify the live Rust
statement field by field with the abstract security statement, and place the
deterministic accepted-call classification inside the causal probability
experiment.  They define the next formal steps without weakening the theorem
reported here.
