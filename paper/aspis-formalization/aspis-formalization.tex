\begin{abstract}
Deploying a cryptographic proof verifier creates a gap between a protocol argument
and the program that accepts a proof.  We present \Aspis{}, a transparent
(trusted-setup-free) private-spend verifier for Solana, together with an
end-to-end formal verification pipeline for its successful proof-checking
path.  The pipeline starts from the deployed Rust verifier, translates the
selected execution path into Lean~4, and proves that every successful call determines
every acceptance-critical value used later in the security argument: the
public-statement digest, Fiat--Shamir transcript and work checks, distinct
queries, authenticated openings, four low-degree-test folds, final polynomial,
and the complete algebraic relation including both final accumulators.  All
are derived from that same execution, with no intermediate acceptance result
supplied as a separate premise.

The mathematical development formalizes the private-spend relation, the
concrete field and evaluation domains, the low-degree and query-sampling
arguments, theft reductions, and the nullifier-controlled state transition.
A single formal experiment classifies accepted false statements into an
ideal-protocol failure and named cryptographic, credential, compiler, and
runtime events.  Under the stated decoding and Fiat--Shamir results, the
work-normalized protocol contribution is at most
\(0.7\cdot2^{-100}\); assuming the external events contribute at most
\(0.3\cdot2^{-100}\), the combined bound is \(2^{-100}\).  A separate raw
accounting gives no credit for completed grinding work.

The evidence package contains a clean 331-module Lean replay, pinned
Rust-to-Lean inputs, a deterministic source-to-binary build, and an archived
mainnet transaction.  The transaction verifies a 75,358-byte proof and
atomically records the nullifier and pool update in 1,334,452 compute units.
The field-level identification of the live Rust statement with the abstract
security statement, and the causal lift of the deterministic result into the
probability experiment, remain explicit composition assumptions.
\end{abstract}
