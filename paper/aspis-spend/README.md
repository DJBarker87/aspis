# Earlier Aspis deployment paper

This directory preserves the earlier deployment-focused manuscript and its
historical release measurements. It is no longer the publication manuscript.

The current arXiv and IACR paper is:

[`paper/aspis-formalization/`](../aspis-formalization/)

That manuscript reports the completed end-to-end accepted-execution theorem,
the conditional security experiment, and the current mainnet evidence in one
paper. Its companion artifact guide maps the readable theorem names to exact
Lean declarations and release records.

The TeX and generated values in this directory remain unchanged so the older
mainnet release can still be reproduced from its original record.
