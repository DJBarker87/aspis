\begin{abstract}
We present \Profile, a transparent argument for a depth-20,
one-input/one-output shielded-spend relation and a Solana program that verifies
it while atomically recording the nullifier and pool transition. The
polynomial-commitment layer is a custom circle-domain, WHIR-style multilinear
protocol at rate $1/512$, with \ProfileQueryCount{} query fibres and
batch-work parameter $g=\ProfileBatchWork$. The frozen event ledger and its
32-boundary Fiat--Shamir reduction give a conservative
\ProfileSoundnessBits-bit floor for work-normalized false acceptance per
random-oracle query under the stated finite-parameter and
boundary-state-restoration premises. Under the stated affine-image premise, an
explicit witness-free simulator gives \ProfileSimulationBits{} bits for real
view versus simulation and \ProfilePairwiseBits{} bits for pairwise
witness-indistinguishability in the declared programmable-SHA-256
Proof-or-Abort view. An accompanying Lean 4 development kernel-checks the
relation core, finite security arithmetic, circle-group facts, masking lemmas,
and theorem composition, with cited cryptographic results kept as named
interfaces.

The released artefact contains a \ProfileProofBytes-byte proof and a
\ProfileSbfBytes-byte Solana bytecode format binary. A finalized mainnet-beta
transaction verified that proof, advanced the pool sequence, created the
nullifier marker, and refunded the proof account in one atomic transition,
using \ProfileMainnetComputeUnits{} of the \ProfileComputeLimit{} requested
compute units. Proof transport and account setup occurred beforehand. The base
claim is argument soundness and conditional computational zero knowledge for
the exact relation and declared view. A separately stated round-by-round
knowledge premise yields the theft-resistance corollary. The demonstrated
relation is a same-path leaf replacement; deposit and a growing anonymity set
are outside this release.
\end{abstract}
