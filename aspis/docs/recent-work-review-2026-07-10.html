CriticalTagged LogUp tuples collide identically across tags

logup.rs:42–50 implements tag + d0 + λd1 + …. Therefore, for every nonzero field element δ, the distinct tuples (tag,d0,…) and (tag+δ,d0−δ,…) produce the same polynomial for every λ. Fixed verifier-computable tags do not prevent the attack: a prover can offset the difference between two wiring tags in the first witness limb.

This falsifies the distinct-polynomial premise used for T6 in aspis-soundness-note.md:381–400. The current test changes a tag and reorders limbs separately, so it misses the coupled collision.

Fix: encode tag + Σ λ^(i+1)d_i, add the coupled tag/value adversarial vector, then recompute the transcript/KAT only if this compression is transcript-visible.

let mut compressed = lift(tag);
let mut power = lambda; // d0 is the λ coefficient, not another constant
for value in values {
    compressed = compressed.add(power.mul_m31(*value));
    power = power.mul(lambda);
}
