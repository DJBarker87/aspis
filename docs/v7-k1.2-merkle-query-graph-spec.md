# V7 K1.2 exact Merkle query-graph specification

Date: 25 August 2026

Status: implementation specification; no extraction theorem is claimed here.

## Scope

This stage adapts the Valiant query-graph component in BCS 2016, Lemma 3.2,
to the exact deployed Tag-73 Merkle grammar.  It is a straight-line
commitment-word extraction step.  It is not the complete BCS argument-of-
knowledge extractor and does not replace K1.3--K1.6.

The implementation target is an executable function of the ordered
SHA-256 query log:

```text
extractV7Words(c1Root, c2Root, orderedQueries)
  -> extracted C1/C2 received words
   | typed extraction failure
```

## Frozen deployed grammar

All digests below are the first 26 bytes of a 32-byte SHA-256 output.

| Item | Exact preimage |
| --- | --- |
| C1 leaf | `0x10 || 0x71 || c1[403] || salt[32]` (437 bytes) |
| C2 leaf | `0x10 || 0xf1 || c2[186] || salt[32]` (220 bytes) |
| Internal node | `0x11 || left[26] || right[26]` (53 bytes) |

Both trees have depth 18 and 262,144 leaves.  The 16 disclosed leaf pairs use
the same 32-byte salt, but the tree tags and values are distinct.  C1 and C2
share the same ordered SHA-256 query log; prefix collisions across the two
typed trees must therefore be one combined failure event, not two independent
assumptions.

The source constants are in:

- `crates/aspis-core/src/state_only_private_merkle.rs`;
- `crates/aspis-core/src/v7_merkle208.rs`; and
- `crates/aspis-core/src/v7_onefold.rs`.

## Ordered graph construction

Deduplicate identical raw SHA-256 inputs while retaining first-query order.
For every query, retain its raw input, full 32-byte answer, and 26-byte prefix.

1. Parse exact typed leaf and node preimages; retain malformed inputs as
   ordinary oracle queries so that their digest prefixes still participate in
   collision checks.
2. Reject or emit `truncatedDigestCollision` if two distinct raw inputs have
   the same 26-byte answer prefix.
3. A node edge to a child digest may resolve only to an earlier query.  A
   child resolved by the same or a later query emits `forwardReference`;
   an unresolved child emits `missingPreimageQuery`/`guessedDigest`.
4. Resolve each supplied root to a unique query and traverse exactly 18 node
   levels.  Missing off-path subtrees receive the extractor's canonical
   default word; an accepted authentication path may not cross such a default
   without emitting a failure.
5. At depth zero require the correct typed leaf grammar.  The extracted word
   contains the fixed-width C1 or C2 value, not the salt.
6. For every accepted paired opening, prove that the extracted values equal
   the disclosed values and that the two typed leaf preimages carry the same
   disclosed salt.

## Required Lean result

The deterministic theorem must have the following shape, with all failure
constructors explicit:

```lean
accepted_two_tree_openings exactV7Grammar roots proof log ->
  (exists words,
      extractV7Words roots log = .words words /\
      wordsMatchRootsAndAllAcceptedOpenings words roots proof)
  \/ V7MerkleExtractionFailure roots proof log
```

Required failure constructors:

- `missingRootQuery`;
- `missingPreimageQuery`;
- `guessedDigest`;
- `forwardReference`;
- `truncatedDigestCollision`;
- `malformedTypedPreimage`; and
- `pairedSaltMismatch`.

The proof must cover the combined two-tree graph and every one of the 16
accepted openings.  A theorem for one abstract ordinary Merkle tree is only a
helper, not K1.2 closure.

## Probability boundary

The random-oracle probability lemma remains a separate interface until it is
proved for this exact prefix/typed grammar.  It must be a raw function of the
total number of distinct SHA-256 queries and must union the collision,
forward-reference, root-guess, and accepted-path missing-query events.

Do not substitute any of the following:

- the generic statement that a 208-bit digest has 104-bit birthday strength;
- the 256-bit Fiat--Shamir capacity term;
- a work-normalized false-acceptance bound; or
- two independent single-tree bounds that ignore the shared oracle log.

BCS Lemma 3.2 proves `(m^2 + 1) / 2^lambda` for its ordinary full-output
binary Merkle grammar.  The V7 constant and query budget must be derived for
the grammar above rather than copied from that lemma.

## Source closure

After the pure theorem passes, extract the production implementations of:

- `truncate_sha256_v7`;
- `private_leaf_hash_v7`;
- `node_hash_v7`; and
- `verify_two_minimal_subtrees_v7_bytes`.

The final source bridge must connect the raw byte parser and ordered hash calls
to the Lean grammar.  SHA-256-as-random-oracle remains an explicit
cryptographic premise; byte grammar, traversal order, and fail-closed result
flow must not remain source-review assumptions.
