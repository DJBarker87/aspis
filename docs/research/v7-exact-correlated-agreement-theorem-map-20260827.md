## Published theorem and exact Lean objects

S-two Theorem 25 is a conservative curve-decodability extraction from
Ben-Sasson--Carmon--Haböck--Kopparty--Saraf Sections 3.1--3.2 and 4.1.
It is stated for the Reed--Solomon code
`RS[F, D, k]`, generated by polynomials of degree strictly less than `k`.  For
a degree-`M` received-word curve and a challenge-indexed family of selected
nearby codewords, it states curve-decodability with

```text
a = ell_GS(theta) * b
b >= ((2 * ell_GS(theta)^4 / 3) * (1 - delta) + 1) * M * |D|.
```

## Initial subcode issue

The released initial message space has dimension 1024, whereas its exact GRS
realization has ambient maximum degree 1024 (a 1025-dimensional ambient
space).  The published full-RS statement therefore cannot be instantiated by
silently replacing the released code with every polynomial of degree at most
1024.  This branch must prove that the released encoder is linear and ensure
that the common curve components are linear combinations of actual released
messages.  Surjectivity onto the ambient degree-1024 polynomial space is
neither true nor required.

## Proof obligations discharged by this branch

1. The exact `LinearMap` and addition/scalar laws for the released initial
   encoder and its exact polynomial image are proved in
   `V7ExactCorrelatedAgreement` and
   `V7ExactCorrelatedAgreementReleasedLift`; in particular, the initial
   degree-1024 ambient space is never treated as the released code image.
2. The curve-decoding argument behind S-two Theorem 25 is reconstructed with the
   actual `forall challenge, selected candidate challenge` strategy.  The
   cited proof is not merely a list-size pigeonhole argument: BCH+25 Lemma
   3.1 constructs one trivariate multiplicity interpolant over the base field;
   Section 3.2 decomposes it into separable factors, chooses a uniform smooth
   specialization, and uses a Hensel lift to obtain one polynomial curve for
   many of the independently selected proximates.  The exact GS list cap by
   itself does not replace these steps.
3. `V7ExactCorrelatedAgreementReleasedLift` proves that the common curve
   remains in the released initial subcode.  The conservative release caps are
   instantiated without changing the production parameters; the exact list
   bounds 100 and 99 alone do not sharpen the weighted factor budget.
4. The resulting selected common curve is fed to the existing root-union
   finalization in `V6Width29CorrelatedAgreement` and
   `V5FriDegreeThreeCorrelatedAgreement` by the two terminal exact V7 theorems.

## Appendix A nonsaturation issue and kernel-checked repair route

BCI+20 Appendix A.2 assigns the integral generator `T` the ceiling weight
`D + ell - ell*d_H` (with `ell = 1` in the printed line case).  In the base
case of Claim A.2, however, the proof says `Lambda(T) = Lambda(W) + ell` for
the leading coefficient `W`.  The stated hypotheses give only
`deg W + ell*d_H <= D`; equality need not hold.  The irreducible monic branch
`H(Y,Z) = Y + Z^2` is a concrete counterexample: its ceiling generator weight
is `2`, while `deg W + 1 = 1`.  Lean proves both irreducibility and this strict
nonsaturation in
`V7ExactCorrelatedAgreementHenselWeights.nonsaturatedLinearBranch_*`.

The reconstruction does not use that informal equality.  It keeps
the fully regular derivative

```text
eta = W^(d_R-1) * (dR/dY)(x0,T/W,Z)
```

instead of cancelling one `W` to use `xi`.  The uniform cleared coefficient
is

```text
delta_t = W * eta^(max(0,2*t-1)) * alpha_t.
```

The convolution exponent identities already proved in
`V7ExactCorrelatedAgreementHenselCombinatorics` leave nonnegative powers of
both `W` and `eta` in every nonlinear recurrence term.  The resulting target
bound is the honest ceiling-weight statement

```text
Lambda(delta_t) <= Lambda(T) + max(0,2*t-1) * Lambda(eta).
```

This bound feeds the published `2*DX*DY^2*DZ` branch sum, so it does not change
either deployed challenge cap.  Formal differentiation lowering the `(ell,1)`
weight by `ell`, the regular `eta` weight, the exact finite-characteristic
support argument, the inductive construction of each `delta_t` in the actual
integral quotient, and the subsequent regular zero-count applications are all
kernel-green in the exact correlated-agreement modules.
